# Project Objectives

## Purpose

Build a lightweight, reproducible Kubernetes observability platform using WSL2 and KinD that serves as an environment for engineering investigation, capability validation and operational experimentation.

The primary goal is not simply to install Prometheus and Grafana, but to understand, measure, document and optimise an observability platform through controlled engineering experiments.

## Objectives

- Build a reproducible Kubernetes observability lab from scratch.
- Document the significant installation, configuration and engineering decisions that shape the platform.
- Establish measurable operational and performance baselines.
- Evaluate changes through controlled experimentation wherever practical.
- Collect observable evidence to support engineering conclusions.
- Explain the rationale behind significant architectural and operational decisions.
- Develop reusable operational tooling that validates platform capabilities through observable evidence rather than resource state alone.

## Target Audience

- Kubernetes learners
- DevOps engineers
- Platform engineers
- Anyone interested in observability on constrained hardware

## Non-Goals

- Production deployment
- High availability
- Enterprise-scale monitoring

This repository focuses on understanding systems rather than deploying production infrastructure.
